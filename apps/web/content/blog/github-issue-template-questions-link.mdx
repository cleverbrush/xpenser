The GitHub support path no longer points contributors toward a disabled Discussions page.

This release came from [PR #37](https://github.com/cleverbrush/xpenser/pull/37) and is now part of the xpenser release archive. It gives people evaluating an [open-source expense tracker](/open-source-expense-tracker) a clearer view of how the product has improved over time.

## What changed

- Updated the issue-template contact link.
- Routed questions and ideas to the feature request form.
- Left the private security contact path unchanged.

## Why it matters

Open-source users need a working place to ask questions, propose ideas, and report self-hosting concerns.

## Where it fits

This keeps xpenser project operations ready for public GitHub traffic.

For a broader product overview, start with the [xpenser home page](/). Developers can also explore the [personal finance API and MCP tools](/personal-finance-api-mcp), while self-hosters can review the [self-hosted personal finance tracker](/self-hosted-personal-finance-tracker) page.
