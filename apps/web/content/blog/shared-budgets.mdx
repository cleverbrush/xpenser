xpenser now supports shared budgets for separating financial activity and collaborating with another user on the same budget.

Budgets create a clear boundary around transactions, categories, vendors, tags, scans, reports, and API workflows. Existing user data is migrated into a Main budget, and new transactions are always created inside a budget.

## What changed

- Added budgets with admin and member roles.
- Added granular budget permissions for transactions, categories, vendors, tags, and member management.
- Added magic-link budget invitations for existing users.
- Moved categories, vendors, tags, scans, reports, Telegram capture, and MCP tools to budget-aware behavior.
- Added a budget selector near the xpenser logo in the web app.

## Why it matters

Personal finance data often needs separation: household spending, business expenses, trip costs, or shared projects can belong in different places. Shared budgets make those boundaries explicit while still allowing trusted collaborators to see and add the same transactions.

## Where it fits

Budgets build on xpenser's existing transaction capture and reporting features. They make the [open-source expense tracker](/open-source-expense-tracker) more useful for shared workflows while preserving the self-hosted model.

For a broader product overview, start with the [xpenser home page](/). Developers can also explore the [personal finance API and MCP tools](/personal-finance-api-mcp), while self-hosters can review the [self-hosted personal finance tracker](/self-hosted-personal-finance-tracker) page.
