The public site footer gained another discovery badge for people finding xpenser through startup directories.

This release came from [PR #48](https://github.com/cleverbrush/xpenser/pull/48) and is now part of the xpenser release archive. It gives people evaluating an [open-source expense tracker](/open-source-expense-tracker) a clearer view of how the product has improved over time.

## What changed

- Added the Huzzler badge to public footer surfaces.
- Kept the badge alongside other discovery links.
- Preserved the normal public navigation experience.

## Why it matters

Directory badges can help an open-source product build early awareness and backlinks without changing the application itself.

## Where it fits

This is part of the public website and SEO/discovery work around xpenser.

For a broader product overview, start with the [xpenser home page](/). Developers can also explore the [personal finance API and MCP tools](/personal-finance-api-mcp), while self-hosters can review the [self-hosted personal finance tracker](/self-hosted-personal-finance-tracker) page.
