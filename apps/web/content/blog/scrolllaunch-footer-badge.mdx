Another public discovery badge joined the xpenser footer as part of the launch and SEO push.

This release came from [PR #51](https://github.com/cleverbrush/xpenser/pull/51) and is now part of the xpenser release archive. It gives people evaluating an [open-source expense tracker](/open-source-expense-tracker) a clearer view of how the product has improved over time.

## What changed

- Added the ScrollLaunch badge to public pages.
- Kept the badge implementation consistent with related footer badges.
- Supported product discovery without changing authenticated app behavior.

## Why it matters

Launch directories can help early users find a project before search rankings mature.

## Where it fits

This contributes to the website presence around xpenser while the app continues to grow.

For a broader product overview, start with the [xpenser home page](/). Developers can also explore the [personal finance API and MCP tools](/personal-finance-api-mcp), while self-hosters can review the [self-hosted personal finance tracker](/self-hosted-personal-finance-tracker) page.
