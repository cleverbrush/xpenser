Reports became more contextual by carrying transaction note information into analysis workflows.

This release came from [PR #21](https://github.com/cleverbrush/xpenser/pull/21) and is now part of the xpenser release archive. It gives people evaluating an [open-source expense tracker](/open-source-expense-tracker) a clearer view of how the product has improved over time.

## What changed

- Added note-aware behavior for transaction reporting.
- Kept report details connected to the underlying transaction records.
- Prepared richer summaries for future report and email insight work.

## Why it matters

Amounts explain what happened, but notes often explain why. Keeping that context near reports makes audits and reviews more useful.

## Where it fits

This helps xpenser serve people who use transaction notes for reimbursements, corrections, vendor context, or personal reminders.

For a broader product overview, start with the [xpenser home page](/). Developers can also explore the [personal finance API and MCP tools](/personal-finance-api-mcp), while self-hosters can review the [self-hosted personal finance tracker](/self-hosted-personal-finance-tracker) page.
