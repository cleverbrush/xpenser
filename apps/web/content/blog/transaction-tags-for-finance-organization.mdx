Transactions gained tags for flexible organization that does not need to fit category hierarchy.

This release came from [PR #47](https://github.com/cleverbrush/xpenser/pull/47) and is now part of the xpenser release archive. It gives people evaluating an [open-source expense tracker](/open-source-expense-tracker) a clearer view of how the product has improved over time.

## What changed

- Added tag support around transaction records.
- Enabled more flexible finance grouping.
- Prepared reporting and filtering workflows for cross-cutting labels.

## Why it matters

Categories answer what kind of transaction it was. Tags can capture projects, trips, reimbursements, tax context, or any user-specific label.

## Where it fits

This gives xpenser users another way to organize personal finance data without overloading categories.

For a broader product overview, start with the [xpenser home page](/). Developers can also explore the [personal finance API and MCP tools](/personal-finance-api-mcp), while self-hosters can review the [self-hosted personal finance tracker](/self-hosted-personal-finance-tracker) page.
