The public xpenser footer gained a Tiny Startups badge as another lightweight discovery surface.

This release came from [PR #49](https://github.com/cleverbrush/xpenser/pull/49) and is now part of the xpenser release archive. It gives people evaluating an [open-source expense tracker](/open-source-expense-tracker) a clearer view of how the product has improved over time.

## What changed

- Added the Tiny Startups badge to the website footer.
- Kept the visual treatment consistent with existing footer links.
- Supported broader product discovery without changing app flows.

## Why it matters

Early distribution work matters for open-source tools. A small footer badge can help people find xpenser from relevant directories.

## Where it fits

This supports the public website and SEO work around xpenser.

For a broader product overview, start with the [xpenser home page](/). Developers can also explore the [personal finance API and MCP tools](/personal-finance-api-mcp), while self-hosters can review the [self-hosted personal finance tracker](/self-hosted-personal-finance-tracker) page.
